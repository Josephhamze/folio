# Folio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A native Mac PDF viewer and editor (read, comment, fill and sign, organize, protect, redact, OCR, compress) on PDFKit.

**Architecture:**
- A SwiftUI `DocumentGroup` of `FolioDocument`, a `ReferenceFileDocument` holding a `PDFDocument`. Every edit goes through `change(_:do:undo:)`, so undo, redo and the edited dot come from one place.
- Each window has a `Viewer` (`@Observable`) that holds the window's state and its `Canvas`, a `PDFView` subclass that draws the annotation tools.
- Pure builders (annotations, rebuilt pages) are free functions, so they can be tested without UI.

**Tech Stack:** Swift 6.4 toolchain in Swift 5 mode (tools 5.9), SwiftUI, AppKit, PDFKit, Vision, Quartz, XCTest. No packages.

**Spec:** `docs/superpowers/specs/2026-10-17-folio-design.md`

## Global Constraints

- macOS 26 or later, Apple Silicon. `swift-tools-version:5.9`, `platforms: [.macOS("26.0")]`.
- Swift with SwiftUI, AppKit (PDFView), PDFKit, Vision and Quartz. No packages.
- `build.sh` makes `build/Folio.app`, signs it with the Apple Development identity (ad-hoc when there is none), and `./build.sh run` restarts it — the same script as Notch's.
- Bundle id `com.josephhamze.folio`; Editor for `com.adobe.pdf` at `LSHandlerRank` Alternate.
- Every change to the document can be undone, is named in Edit › Undo, and marks the document edited.
- Every tool, button and menu item that changes the document is disabled while `!doc.canEdit` (locked, or restricted without its permissions password).
- Functions that touch PDFKit objects or the undo manager run on the main actor; async tests that call them are `@MainActor`.
- A save never strips a file's password unless asked to.
- Simplest working code, fewest lines, no wrappers or abstraction layers; comment only non-obvious logic; British spelling in UI copy ("colour").
- Repo `~/Claude Work /Folio` (note the space). Work on branch `build`; commit after every task; merge to `main` at the end. Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Live checks capture only Folio's window (`screencapture -l <window id>`), never the whole screen. Never type into another app: check that Folio is frontmost first.

## Review Focus

- **Encrypted and restricted files.** Opening, editing and saving keep the file's own protection. New protection replaces it. A restricted file can't be edited until its permissions password is given. (Tests in Tasks 1 and 7.)
- **Rotated pages and pages whose media box doesn't start at 0,0.** Redaction blacks out exactly the boxed area. OCR's text lands on the words. Rotation and crop box survive. (Tests in Task 8.)
- **Form fields.** A typed value marks the document edited and can be undone; it is never lost on close. (Test in Task 5, plus a live check.)
- **Photos inserted or combined.** They land on a paper-sized page (landscape for wide images), not a page the size of the photo in points. (Test in Task 2.)
- **Find with no query or no matches.** Highlights clear and nothing crashes. Stepping wraps around. (Test in Task 4.)

**Interfaces:**
- Produces, in `Document.swift`:
  - `@Observable final class FolioDocument: ReferenceFileDocument, @unchecked Sendable`, with `static let readableContentTypes: [UTType] = [.pdf]`.
  - `var pdf: PDFDocument`; `var revision: Int` (it goes up on every change); `var password: String?` (the one that unlocked the file); `@ObservationIgnored var undo: UndoManager?`.
  - `init()` makes one blank page via `static func blankPage() -> PDFPage`, with its media box at `NSPrintInfo.shared.paperSize`. `init(pdf: PDFDocument)`. `init(configuration:)` uses `PDFDocument(data:)`, else throws `CocoaError(.fileReadCorruptFile)`.
  - `snapshot(contentType:)` returns `pdf.dataRepresentation()`; it throws when the document is locked or the data is nil. `fileWrapper(snapshot:configuration:)`.
  - `func unlock(_ password: String) -> Bool`: on success it stores `password` and bumps `revision`.
  - `var canEdit: Bool`: not locked, and either not encrypted, or `permissionsStatus == .owner`, or `allowsDocumentChanges && allowsDocumentAssembly && allowsCommenting && allowsFormFieldEntry`.
  - `func change(_ name: String, do: @escaping () -> Void, undo: @escaping () -> Void)`: runs `do`, bumps `revision`, and registers the reverse pair with `undo` under `name`, so redo works.
- Produces, in `Window.swift`:
  - `@Observable final class Viewer { let doc: FolioDocument; @ObservationIgnored lazy var canvas = Canvas(viewer: self); init(doc:) }`.
  - `struct DocumentView: View`. It is built with `init(doc:)` and keeps `@State var viewer`. It shows the canvas through an `NSViewRepresentable` that sets `canvas.document = viewer.doc.pdf` whenever that is a different object. It passes `@Environment(\.undoManager)` to `doc.undo` on appear and on change.
- Produces, in `Canvas.swift`: `final class Canvas: PDFView { unowned let viewer: Viewer; init(viewer:) }`. It sets `autoScales = true` and `displayMode = .singlePageContinuous`, and in `viewDidMoveToWindow` sets `window?.tabbingMode = .preferred`.
- Produces, in `App.swift`: `@main struct FolioApp: App` with `DocumentGroup(newDocument: { FolioDocument() }) { DocumentView(doc: $0.document) }`.

**Interfaces:**
- Consumes: `change`, `FolioDocument.blankPage()`.
- Produces, on `FolioDocument`:
  - `var pages: [PDFPage]`.
  - `func setPages(_ pages: [PDFPage], name: String)`: removes every page and inserts these. Its undo restores the previous list of the same `PDFPage` objects.
  - `func rotate(_ pages: [PDFPage], by degrees: Int)` (undo name "Rotate").
  - `func delete(_ pages: [PDFPage])` ("Delete Pages").
  - `func insert(_ new: [PDFPage], at index: Int)` ("Insert Pages").
  - `func move(_ moving: [PDFPage], to index: Int)` ("Move Pages"). `index` is a slot in the current list, counted before the moving pages are removed.
  - `func extract(_ pages: [PDFPage]) -> PDFDocument`: copies of the pages, in document order.
  - `func split(every n: Int, into folder: URL, name: String) throws -> [URL]`: files `"<name> 1.pdf"`, `"<name> 2.pdf"`, and so on.
  - `static func pages(from urls: [URL]) -> [PDFPage]`:
    - PDFs give copies of their pages; locked PDFs are skipped.
    - Images become `PDFPage(image:options:)` with `.mediaBox` set to the paper rect, landscape when the image is wider than tall.

### Task 3: Annotation builders

**Files:**
- Create: `Sources/Folio/Annotations.swift`
- Test: `Tests/FolioTests/AnnotationTests.swift`

**Interfaces:**
- Consumes: `change`, `makePDF`, `manualUndo`, `act`.
- Produces, in `Annotations.swift`:
  - `enum Tool: String, CaseIterable, Identifiable { case select, highlight, underline, strike, note, text, rect, oval, line, arrow, pen, sign, editText, redact }`, with `var name: String` and `var symbol: String` (an SF Symbol).
  - `func markups(_ selection: PDFSelection, type: PDFAnnotationSubtype, color: NSColor) -> [(page: PDFPage, annotation: PDFAnnotation)]`: one annotation per line, with `quadrilateralPoints` relative to its bounds.
  - `func shape(_ tool: Tool, from: CGPoint, to: CGPoint, color: NSColor) -> PDFAnnotation`:
    - rect → Square and oval → Circle, both with a border of width 2.
    - line and arrow → Line, with bounds inset by -10 and start and end points relative to the bounds; arrow has `endLineStyle = .openArrow`.
    - redact → Square with a red border, a red interior at alpha 0.25, and `.name` set to `"folio-redaction"`.
  - `func ink(_ strokes: [[CGPoint]], color: NSColor, width: CGFloat) -> PDFAnnotation`: bounds = the strokes' box inset by `-width`; the paths are relative to the bounds.
  - `func coverLine(at point: CGPoint, on page: PDFPage) -> PDFAnnotation?`:
    - It uses `page.selectionForLine(at:)` and returns nil when there's no text there.
    - Otherwise a FreeText covering the line's bounds (padded by 2), with contents set to the line's text.
    - Its font is that of the line's first character (`attributedString`), `fontColor` black, `color` white, and border width 0.
  - `extension PDFAnnotation`:
    - `var isRedaction: Bool`.
    - `var isComment: Bool`: Text, FreeText, Highlight, Underline, StrikeOut, Square, Circle, Line or Ink, and not a redaction.
  - `enum Signature: Codable, Equatable { case drawn([[CGPoint]]), typed(String) }`:
    - `static var saved: Signature?` is JSON in `UserDefaults.standard` under `"signature"`.
    - `func annotation(in rect: CGRect) -> PDFAnnotation`:
      - Drawn: an ink annotation, black, width 2, with the strokes fitted into `rect` keeping their aspect.
      - Typed: a FreeText in `SnellRoundhand` at `rect.height * 0.7`, black, with `color` clear and no border.
    - `var aspect: CGFloat` (width over height; typed is 4).
  - `extension FolioDocument`:
    - `func add(_ a: PDFAnnotation, to page: PDFPage, name: String)` and `func remove(_ a: PDFAnnotation)` ("Delete").
    - `func set<V>(_ key: ReferenceWritableKeyPath<PDFAnnotation, V>, of a: PDFAnnotation, to value: V, name: String)`.
    - `var comments: [(page: PDFPage, annotation: PDFAnnotation)]` (in page order, `isComment` only).
    - `var hasRedactions: Bool`.
