# Folio for iPhone and iPad: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Mac app's sources also build an iPhone and iPad app, ready for the App Store, with the Mac app unchanged in behaviour.

**Architecture:**
- On iOS, `Platform.swift` gives UIKit's types the AppKit names the shared code uses. Mac-only code is fenced with `#if os(macOS)`.
- `Canvas` keeps one class. What a tool does at a page point moves into shared `begin`, `extend` and `end` methods. The Mac's mouse handlers and the iOS gestures (`Touch.swift`) both call them.
- An XcodeGen `project.yml` builds the iOS app from the same `Sources/Folio` folder (synced), plus `iOS/` for its plist, privacy manifest and assets.

**Tech Stack:** Swift 5 mode. SwiftUI, PDFKit, AppKit on macOS 26, UIKit on iOS 26. XcodeGen 2.45 (installed) for the iOS project. No new packages.

**Spec:** `docs/superpowers/specs/2026-10-21-ios-design.md`

## Global Constraints

- macOS 26 (SwiftPM, `swift-tools-version:5.9`, unchanged) and iOS 26.0. `TARGETED_DEVICE_FAMILY` `1,2`.
- Bundle ID `com.josephhamze.folio`. Team `PP6TZWTTLG`. `MARKETING_VERSION` 1.0. The build number is `git rev-list --count HEAD` for releases, 1 otherwise.
- The Mac app's behaviour, `swift test`, `./build.sh`, `./build.sh run` and `./build.sh dmg` must not change. Run `swift test` after every task that touches `Sources/`.
- Every document change goes through `FolioDocument.change`. Text boxes fall back to Helvetica 12 in black.
- No new frameworks or packages. `Folio.xcodeproj` is generated and gitignored.
- Branch `ios`. Commit after each task. Merge to main and push at the end.
- iOS simulator for builds and tests: `platform=iOS Simulator,name=iPhone 17 Pro` (iOS 26.5). iPad checks use `iPad Pro 13-inch (M5)`.

## Review Focus

1. **A locked or restricted file on iOS.** A tool must not mark it: a pan or tap with the Pen or Note tool adds nothing. Tested in Task 3.
2. **A zoomed page.** At `scaleFactor` 2, a tap with the Note tool puts the note at the tapped page point. Tested in Task 3.
3. **A highlight dragged across a page break.** Both pages get their lines marked, as one undo step. Tested in Task 3.
4. **Leaving the app, or closing the document, mid-typing.** The words are kept. The `Viewer.settle()` path is tested in Task 3. The scene-phase wiring is checked on the simulator in Task 4.
5. **Two fingers with a drawing tool on.** They scroll and zoom, and don't draw: the tool's pan takes one touch only. Asserted in Task 3, and tried by hand on the simulator in Task 4.

### Task 2: Tools act through shared methods

**Files:**
- Modify: `Sources/Folio/Canvas.swift`
- Test: `Tests/FolioTests/ViewerTests.swift`

**Interfaces:**
- Consumes: `shape`, `ink`, `markups`, `textBox`, `coverLine` and `Signature` from `Annotations.swift`.
- Produces, all in page space and shared:
  - **`func begin(at point: CGPoint, on page: PDFPage) -> Bool`**
    - Returns false when the file can't be edited.
    - It sets `start` and `stroke`, then acts per tool:
      - **Select:** picks a mark (not Widget, Link or Popup) and keeps its bounds in `origin`. Returns true.
      - **Select, on no mark:** sets `selected = nil`. Snapshots the form fields when the press is on a Widget. Returns false.
      - **Highlight, Underline, Strike Through:** returns false.
      - **Note:** adds the note, then sets `pane = .comments`, `showsPanes = true`, `focusNote`, and the Select tool.
      - **Text Box:** chooses Select, then edits `textBox(at:on:)`, adding "Add Text".
      - **Edit Text:** edits the cover, adding "Edit Text", and warns once.
      - **Sign and Initial with nothing saved:** clears `start` and opens the pad.
    - Returns true for every other tool.
  - **`func extend(to point: CGPoint) -> Bool`**
    - **Select:** moves the picked mark from `origin`.
    - **Rectangle, Oval, Line, Arrow, Redact, Pen, Sign, Initial:** redraws the draft.
    - Returns false otherwise.
  - **`func end(at point: CGPoint)`**
    - **Select:** a move becomes one "Move" change.
    - **Shapes, Pen and Redact:** the draft becomes one change: "Add Shape", "Draw" or "Mark for Redaction".
    - **Sign and Initial:** places the draft, or 180×45 centred on the point when there's no draft, under the tool's name, then chooses Select.
    - It always clears `start`, `origin` and `draft`.
  - **`func markUp(_ selection: PDFSelection)`**: `markups` for the current tool and colour, added as one change named after the tool.
  - **`Viewer.showsPanes: Bool`**: the iOS inspector. **`Viewer.mark: PDFAnnotation?`**: set by `Canvas.selected`'s didSet, for the views.

### Task 3: Touch and Pencil on iOS

**Files:**
- Create: `Sources/Folio/Touch.swift`, all of it `#if os(iOS)`

- Test: `Tests/FolioTouchTests/TouchTests.swift`

**Interfaces:**
- Consumes: Task 2's `begin`, `extend`, `end` and `markUp`.
- Produces:
  - **`Canvas.tapped(at point: CGPoint)`**, in view coordinates:
    - First `finishEditing()` and `commitFields()`.
    - A tap on the selected FreeText edits its words.
    - Otherwise `begin`, then `end` at the same point.
  - **`Canvas.panned(_ state: UIGestureRecognizer.State, at point: CGPoint)`**, in view coordinates:
    - **Markup tools:** the document's selection from the start page and point to the current page and point (`PDFDocument.selection(from:at:to:at:)`) becomes `currentSelection`. At `.ended` it goes to `markUp`, then `clearSelection()`.
    - **Other tools:** `begin`, `extend` and `end`, with each point taken into the start page's space.
  - **The pan recognizer:** `maximumNumberOfTouches = 1`. It begins only when the file can be edited and the touch is on a page, and only with one of these:
    - a markup, shape, Pen or Redact tool
    - Sign or Initial, with one saved
    - Select, inside the selected mark's bounds
  - **Scrolling:** the scroll view's pan recognizers require it to fail.
  - **The tap recognizer:** recognizes alongside PDFKit's own, so links and form fields still work.
  - **Form fields:** `gestureRecognizer(_:shouldReceive:)` snapshots the fields of the page under a touch on a Widget. `UITextField.textDidEndEditingNotification`, from a field inside the canvas that isn't the editor, commits them.
  - **The editor:** a `UITextField` in `documentView` at the box's frame, with the font at `pointSize × scaleFactor`.
    - Return ends the typing, and so does a tap elsewhere.
    - `editingChanged` widens it to its words.
    - Check on the simulator that `documentView` subviews scroll and zoom with the page. If they don't, put the field and the outline in the canvas, and end the typing on `.PDFViewScaleChanged` and on scroll.
  - **`Viewer.settle()`**: `canvas.finishEditing()` then `canvas.commitFields()`.
